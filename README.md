# 🌟 Guild Code Community Platform

A modern community platform built to connect developers, showcase projects, promote collaboration, and manage community events.

> Built with the MERN Stack (MongoDB, Express.js, React, Node.js).

---

## 📖 Overview

Guild Code Community Platform is designed to provide a centralized space where developers can:

- Showcase their projects
- Connect with other community members
- Find collaborators
- Participate in events
- Build professional profiles
- Engage with the Guild Code community

The platform also includes a comprehensive administration system for managing members, projects, collaborations, and community events.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Winney360/Guild_Code_Community_Hub.git
```

```bash
cd Guild_Code_Community_Hub
```

---

## 📦 Installation

### Frontend

```bash
cd client
pnpm install
pnpm run dev
```

---

### Backend

```bash
cd server
pnpm install
pnpm run dev
```

---

## ⚙ Environment Variables

Create a `.env` file inside the backend directory.

```env
PORT=

MONGODB_URI=

JWT_SECRET=

CLIENT_URL=

CLOUDINARY_CLOUD_NAME=

CLOUDINARY_API_KEY=

CLOUDINARY_API_SECRET=
```
